Fulldesign Skin Studio

Aplicativo Android independente para criação, edição, conversão e montagem de packs de skins para CS 1.6 Mobile.

Objetivos

- Editor e conversor de texturas.
- Suporte a modelos GoldSrc.
- Visualizador 3D.
- Montagem de packs de armas, braços e luvas.
- Exportação para clientes compatíveis de CS 1.6 Mobile.

Estado do projeto

Em desenvolvimento. O APK ainda precisa ser compilado e testado.
